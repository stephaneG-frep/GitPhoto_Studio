# Branches

A **branch** is a parallel line of versions in a repository. The main branch is usually called `main` (sometimes `master`).

## What they are for

You create a branch to prepare changes without touching the main version, then merge them when ready. To publish photos, the main branch is almost always enough.

## In GitPhoto Studio

- The publishing wizard suggests the repository's **default branch**; you can choose another existing one.
- On the GitHub screen, browsing a repository shows the chosen branch and its latest commits.
- The app **does not create** branches and **never forces** a publication: if the branch moved in the meantime, it adapts or stops, without overwriting anything.

> Branches can be created and merged on github.com if you need them.
