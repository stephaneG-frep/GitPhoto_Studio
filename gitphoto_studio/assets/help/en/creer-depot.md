# Creating or choosing a repository

A **repository** is an online folder on GitHub that keeps the history of all its versions. You can use an existing one or create one.

## Create a repository

1. [GitHub](app:/github) screen › **New repository**.
2. Choose a name: letters, digits, "-", "_" and "." only, 100 characters at most.
3. Add a description if you like.
4. Choose the visibility:
   - **Private**: visible to you and the people you invite. Recommended for personal photos.
   - **Public**: visible to everyone on the Internet. The app asks for a **second confirmation**.
5. Tap **Create**.

The token needs the **Administration** write permission; otherwise create the repository on github.com and add it to your token.

> A public repository also shows your photos' metadata, including the **GPS position**. Optimize your images before publishing: optimized copies contain none.

## Choose the active repository

Open a repository in the list, then **Set as active repository**. It is suggested by default in the publishing wizard, and its latest commits appear on the Home screen.

## Browse a repository

When you open a repository you see its folders and files, the **branch** shown (you can change it) and its latest commits. **Publish here** opens the wizard with this repository, branch and folder already chosen.

See also: [Branches](help:branches), [Publishing a photo](help:publier-photo).
